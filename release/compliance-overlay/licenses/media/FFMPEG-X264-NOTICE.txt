VRhino includes a separately executed media component based on FFmpeg 4.4.2.
This FFmpeg build includes libx264 from x264 source revision:

  5db6aa6cab1b146e07b60cc1736a01f21da01154

The resulting FFmpeg build is distributed under GPL-2.0-or-later. The FFmpeg
configuration enables GPL, libx264, libswresample, and libsoxr. It does NOT use
--enable-nonfree. The v0.5.0-alpha bounded lip-sync additions are inventoried
in `licenses/media/LIP-SYNC-MEDIA-EXTENSIONS.txt`, including the native FFmpeg
Matroska/image2/PNG-pipe demuxers and FFV1/PNG decoders. These introduce no
external codec library; PNG decoding uses the already bundled zlib.

The proprietary VRhino Runtime does not directly link to libavcodec,
libavformat, libavutil, libavfilter, libswscale, libswresample, libx264, or
libsoxr, and does not
dynamically load them. VRhino executes vrhino-ffmpeg as a separate process and
sends standard flat RGB24 video frames to its stdin pipe. This notice describes
