# v0.9.0-alpha release candidate

Status: local packaging and release preparation. Not yet published.

This alpha adds Wan2.2-T2V-A14B native video-generation support through the
explicit `vrhino evaluate` entry, including native text conditioning, declared
component selection and sampling, decoding and video output. It also adds generic
schema2 package admission and configurable weight-cache budgets.

See [Wan2.2 alpha support](v0.9-wan2.2-known-limitations.md) for tested settings
and [Product evaluation](../product/bounded-evaluation.md) for the current entry.
Ordinary schema2 `run` support is pending. Existing schema1 product paths remain
supported subject to their existing model and hardware requirements.

Packaging target under preparation: Linux x86_64 CUDA. The current validation
host is an NVIDIA A800 80 GB on Linux; v0.9 Windows binaries have not been
qualified. Archive identities and final compatibility results will be recorded
with the prepared assets.

Model weights and VRM files are acquired separately and are not bundled.
Wan2.2 numerical alignment and wider configuration coverage continue to mature;
start with the documented tested configuration. Developer qualification records
remain separate from this alpha support designation.
