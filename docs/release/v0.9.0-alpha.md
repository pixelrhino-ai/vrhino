# v0.9.0-alpha — Linux CUDA

Published on 2026-09-20 (UTC) as a
[GitHub alpha prerelease](https://github.com/pixelrhino-ai/vrhino/releases/tag/v0.9.0-alpha).

This release adds Wan2.2-T2V-A14B native text-to-video through `vrhino evaluate`,
generic schema2 package admission, declared dual-binding execution/sampling,
and configurable weight-cache budgets. See [installation](../install.md), the
[Wan2.2 quick start](../models/wan2.2-quickstart.md)
([中文](../models/wan2.2-quickstart.zh-CN.md)), and
[tested settings](v0.9-wan2.2-known-limitations.md).

## Scope

Linux x86_64 CUDA only; built with CUDA 12.8 for SM80, requiring glibc 2.35 or newer.
Tested on NVIDIA A800 80 GB. User-space libraries and media encoding are bundled;
model weights and VRMs are not. Native execution does not require Python.
Windows users continue with the [v0.8 package](v0.8.0-alpha.md).

Wan2.2 uses `evaluate`; ordinary schema2 `run` support remains pending.
Existing schema1 paths retain their previously documented model/platform scope.
The three reviewed BF16 videos used 832×480, 81 frames, 40 steps and a 30 GiB
weight cache, with about 44.8 GiB observed peak device memory and 14–14.5 minutes
per video. These are tested observations, not guarantees for other configurations.
