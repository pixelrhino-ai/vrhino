# v0.8.0-alpha release record

Status: **qualified for prerelease publication**.

v0.8.0-alpha is the first VRhino release line with a qualified native Windows
x64 CUDA product. Both frozen binary assets were built from
`d460de0a152c9ff92553b17ca37e4b5554c8c766`. The release tag may point to a
later documentation-only commit; the binary build-source identity remains the
full commit above.

## Windows qualification

The exact rc9 ZIP passed final clean-host qualification on Windows 10 Pro
22H2 / build 19045 with an NVIDIA RTX 3090 24 GiB and NVIDIA driver 610.47.
This is a tested baseline, not an exact minimum-driver requirement or a claim
covering every Windows version, GPU, or driver.

The self-contained package uses 39 application-local runtime DLLs and includes
its CUDA/cuDNN/NVRTC and media runtime. End users do not install CUDA Toolkit,
standalone cuDNN, Visual Studio/Build Tools, CMake, Ninja, Python, PyTorch,
Diffusers, Transformers, Conda, system FFmpeg, MSYS2/MinGW, or WSL.

Packaged remote import passed for all five public models. Mochi's frozen
minimum available device-memory admission remains 85,899,345,920 bytes. Its
full inference was not run on this 24 GiB host; this is not a failed model test
and the admission was not reduced.

MuseTalk and LatentSync passed technical execution and complete media
validation. No calibrated qualification-grade objective lip-sync threshold is
frozen, so their separate objective quality gates remain **deferred**. No
objective quality PASS is claimed.

## Linux qualification

The exact Linux archive has release-readiness PASS. Packaged remote import for
all five public models passed. Wan, LTX, MuseTalk, and LatentSync passed their
qualified product paths. Mochi full inference was not rerun on the 24 GiB
qualification host; historical Linux Mochi qualification is preserved and its
admission is unchanged.

The Linux x86_64 CUDA package requires glibc 2.35 or newer and a compatible
NVIDIA GPU and driver. The qualification evidence does not claim universal
Linux distribution or GPU compatibility.

## Change and support boundary

This release includes the shared source-plan resolution fix. Source acquisition
resolution changed. Architecture, Runtime, backend, CUDA, kernel, precision,
model-specification, and preset semantics remain unchanged.

The published v0.7.0-alpha release remains immutable and Linux-scoped. Its tag,
release description, and assets are unchanged; no Windows asset is added to it.
macOS support is not claimed.

Native API v1 remains local-first. It binds to `127.0.0.1:11435` by default and
has no authentication, TLS, or CORS policy. Do not expose it directly to an
untrusted network. See [Alpha limitations](../alpha-limitations.md) for the full
product boundary.
