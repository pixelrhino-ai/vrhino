Status: **unreleased; rc7 build and exact-candidate qualification pending**.
v0.8.0-alpha is the first Windows-supporting release line. This version PR
prepares the release identity and documentation; it does not publish a release
or certify bytes that have not yet been built.

## Windows scope and evidence

19045, NVIDIA GeForce RTX 3090 (24 GiB), driver 610.47. This is a tested

## Version-bearing surfaces

- `VERSION` is the canonical current identity, v0.8.0-alpha. CMake derives
  numeric 0.8.0, CLI/API version data and generated package metadata from it.
- The strict release-version test updates its two explicit version
  expectations and retains CLI/API/CMake/package consistency assertions.
- The Windows assembler reads canonical Git VERSION bytes and checks the
  executable version and source commit before generating SOURCE-BUILD.json.
  Its implementation does not need a version-specific change.
- Current release status, installation guidance and platform scope are
  updated; old release-note sections, published asset identities, model
  package versions and v0.6 contract examples remain historical references.
  The existing v0.6 public-contract validator is retained without weakening
  its frozen model hashes, API examples or documentation checks.

Only release metadata, documentation and version-test expectations change.
Architecture, Runtime, backend, CUDA, kernels, precision, model specifications
and presets retain their semantics.

## Candidate and qualification handoff

After the version PR passes required CI and is squash merged, build rc7 from
that exact new main commit on a **separate Windows developer environment**.
Do not reinstall developer tooling on the preserved clean qualification host.
Do not reuse the rc6 stage or executable. The candidate name is
`vrhino-windows-x86_64-cuda-v0.8.0-alpha-<commit7>-rc7.zip`.
No concrete rc7 commit, download URL or hash exists at preparation time.

Run the existing [Windows packaging gates](../windows-packaging.md), including
the 39 application-local DLL closure, local NVRTC and builtins, 83 converter
resources, licenses/provenance, SHA256SUMS, private-path rejection with the
documented vendor-metadata exception, relocation/Unicode/unrelated CWD,
sanitized environment, reproducible ZIP, archive security, cache publication,
CLI and >2 GiB / >4 GiB converter regressions. Compare rc7 with rc6: permit
version/provenance changes, but stop on unexpected implementation, toolchain,
tokenizer, CUDA/cuDNN or dependency drift. Do not add nvJitLink without evidence.

Transfer only the frozen rc7 ZIP and its checksum/freeze metadata to the
clean host, verify the hash, and extract a new installation. Application DLLs
must load only from rc7; Windows and NVIDIA driver modules remain the only
external runtime boundary. Old candidates and historical DLL stores must
remain outside the product loader search paths.

Wan and LTX must exercise rc7 conversion/install, doctor and one real frozen
run each, starting without an installed model. Reuse hash-verified original
source material where available; a version-only change does not require an
