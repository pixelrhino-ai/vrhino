# v0.9.1-alpha — Linux CUDA

[Download the Linux alpha prerelease](https://github.com/pixelrhino-ai/vrhino/releases/tag/v0.9.1-alpha).

This update brings Wan2.2-T2V-A14B to the ordinary `vrhino pull` and `vrhino run`
Product path and ships one Linux CUDA package with native images for SM 80, 86,
89, 90 and 120 plus compute 80 PTX. The package includes the native converter,
tokenizer and media helpers; model weights remain separate. Existing model
commands and the v0.9.0-alpha release remain available.

```sh
curl -fsSL https://raw.githubusercontent.com/pixelrhino-ai/vrhino/main/install.sh | sh
vrhino pull vrhino/wan2.2-t2v-a14b:1.0.0
vrhino run vrhino/wan2.2-t2v-a14b:1.0.0 \
  --prompt "a red panda running through fresh snow" --output video.mp4
```

See the [short Wan2.2 guide](../models/wan2.2-quickstart.md) or its
[Chinese edition](../models/wan2.2-quickstart.zh-CN.md) for storage and hardware
details. Linux x86_64, glibc 2.35 or newer, a compatible NVIDIA driver and
sufficient model memory are required. Windows users continue with the v0.8
release.

## Qualification scope

The multi-architecture candidate completed normal Product video runs on an
A800 with Wan2.2 A14B and on an RTX 4090 with Wan2.1 1.3B. The same CUDA image
layout is present in this versioned archive. Its packaged commands, checksums,
CUDA images and installer are separately verified. Hardware and model memory
requirements vary by configuration; these results are observations, not a
universal performance or memory guarantee.

The public test suite passes 77 of 78 cases on the current qualification host.
The remaining generic F32 LayerNorm finite-offset case reproduces a previously
documented alpha issue. Generic BF16 reference numerical qualification remains
open. The alpha path is usable under the tested configurations; these research
gates are not relabeled as PASS. Details are in the
[Wan2.2 alpha notes](v0.9-wan2.2-known-limitations.md).
