# Wan2.2 support in v0.9 alpha

Wan2.2-T2V-A14B has completed native video-generation tests in VRhino,
including text conditioning, sampling, VAE decoding and video output.
In three comparisons with the official implementation, project review found
similar visual quality and prompt adherence.

## Tested configuration

Linux · NVIDIA A800 80 GB · BF16 · 832×480 · 81 frames · 40 steps.
With a 30 GiB weight-cache budget, observed peak GPU memory was approximately
44.8 GiB and generation took approximately 14–14.5 minutes in these tests.
Results depend on hardware and generation settings.

For setup and commands, start with the [Wan2.2 quick start](../models/wan2.2-quickstart.md)
([中文](../models/wan2.2-quickstart.zh-CN.md)); the full command reference is
[Product evaluation](../product/bounded-evaluation.md).
Wan2.2 currently uses `vrhino evaluate`; ordinary schema2 `run` support is pending.

## Alpha notes

Wan2.2 support is in alpha. Numerical alignment with the reference implementation
and coverage of additional devices and generation settings are still being
refined. Start with the tested configuration when possible, and include your
hardware and settings when reporting an issue.

A known F32 normalization edge case remains under investigation; it has not been
observed in the three reviewed BF16 video runs. Detailed test results and
qualification status are available in the
[developer notes](../protocol/v0.9-wan2.2-qualification-notes.md).
