# VRhino v0.9.3-alpha

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/pixelrhino-ai/vrhino/v0.9.3-alpha/install.sh | sh
```

## Downloads

- **Core:** `vrhino-core-linux-x86_64-v0.9.3-alpha.tar.gz`
- **NVIDIA Runtime:** `vrhino-nvidia-runtime-linux-x86_64-cuda12.8-cudnn9.8-r1.tar.gz`

The installer verifies both packages and manages the exact NVIDIA dependency
automatically. Normal users do not need to download the runtime manually.
First installation downloads both packages. A later core upgrade still
downloads the new core; if it requires this exact R1 runtime, the verified
private runtime is reused without another download.

Linux x86_64, glibc 2.35 or newer, a compatible NVIDIA GPU and driver, and
sufficient VRAM and disk space are required. No system CUDA Toolkit or cuDNN
installation is required.

This alpha organizes the distribution. It does not change inference or CUDA
numerics. The included executable was built as `v0.9.1-alpha` from source
commit `df27ee5eb4b987fa4cb6e83d744f001d61883595`; `vrhino --version`
reports that real binary build. The v0.9.3-alpha tag names this distribution
release. The historical Wan2.2 numerical HOLD is unchanged.

For offline installation, download both packages and the versioned
`tools/install_distribution_v2.sh` from this tag into one directory, then run
the versioned `install.sh --bundle-dir DIR`. The bootstrap checks the helper
SHA and both package SHA values. The existing repository
`tools/rollback_distribution_v2_legacy.sh` switches a migrated v0.9.1
installation back to its preserved copy.

The two package identities and installer helper pin are recorded in the
[repository metadata](v0.9.3-alpha-assets.json). Neither this metadata nor
the helper is a Release download asset.
